GitHub 개인 토큰 (선택 · 이 브라우저에만 저장 · api.github.com 에만 전송)

      
토큰이 없으면 같은 네트워크(IP)를 쓰는 전원이 시간당 60회를 나눠 씁니다 (새로고침 1번 ≈ 브랜치 수+3회). 본인 GitHub 계정으로 만든 읽기 전용 토큰을 넣으면 내 계정만 시간당 5,000회가 됩니다. 방장 토큰을 받아 쓰는 게 아니라 각자 자기 계정으로 만드세요.

      
      

      
토큰 만드는 법 (1분 · 읽기 전용이라 유출돼도 계정에 피해 없음)
        
    
          
  1. GitHub에 본인 계정으로 로그인한 뒤 github.com/settings/personal-access-tokens/new ↗ 열기
    (메뉴로 가려면: 우상단 프로필 → Settings → 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token)
    2. 
          
  2. Token name: 아무거나 (예: psboard) · Expiration: 스터디 기간보다 길게
    3. 
          
  3. Repository access: Public repositories (read-only) 선택 — 아래 Permissions 는 건드리지 않아도 됩니다. 공개 저장소 읽기만 되는 토큰입니다.
    4. 
          
  4. 맨 아래 Generate token → github_pat_… 를 복사 (화면을 벗어나면 다시 볼 수 없으니 바로 복사)
    5. 
          
  5. 위 칸에 붙여넣고 토큰 확인 → 아래 저장
    6. 
        

      

    

    
현황판은 GitHub를 읽기만 합니다 (토큰 없음: IP당 시간당 60회 · 토큰 있음: 계정당 시간당 5,000회 · 새로고침 1번에 브랜치 수+3회 사용 · 10분 캐시). 쓰기는 전부 내 로컬 폴더에만 하고, GitHub에 올리는 건 직접 커밋/푸시할 때뿐입니다.
