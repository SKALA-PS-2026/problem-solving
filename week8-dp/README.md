## 🎯 이번 주 핵심 개념

### 1. DP가 뭔지: 피보나치로 보는 문제점

피보나치를 그냥 재귀로 풀면 이렇습니다.

```python
def fibo(n):
    if n <= 1:
        return n
    return fibo(n-1) + fibo(n-2)
```

문제는 **같은 계산을 계속 반복**한다는 겁니다. `fibo(5)`를 구하려면 `fibo(3)`을 여러 번 다시 계산하게 됩니다. n이 커질수록 중복 계산이 기하급수적으로 늘어나서 매우 느려집니다.

**DP는 "한 번 계산한 결과를 저장해뒀다가 재사용"해서 이 중복을 없애는 방법**입니다.

<br>

### 2. 메모이제이션 (Top-down)

재귀에 **캐싱**을 더한 방식입니다. 이미 계산한 값이면 저장된 값을 바로 반환합니다.

```python
memo = {}

def fibo(n):
    if n <= 1:
        return n
    if n in memo:
        return memo[n]
    memo[n] = fibo(n-1) + fibo(n-2)
    return memo[n]
```

<br>

### 3. 타뷸레이션 (Bottom-up)

재귀 없이 **반복문으로 작은 값부터 차례로 테이블을 채워나가는** 방식입니다.

```python
def fibo(n):
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

**둘 다 결과는 같지만**, 타뷸레이션은 재귀 호출이 없어서 더 빠르고, 재귀 깊이 제한 문제도 없습니다. 메모이제이션은 점화식을 그대로 코드로 옮기기 쉬워서 구현이 더 직관적일 때가 많습니다.

<br>

### 4. 점화식 세우는 법

DP 문제의 핵심은 **"현재 상태를 이전 상태로 어떻게 표현할 것인가"**를 찾는 것입니다. 이게 점화식입니다.

**예: 계단 오르기** — 한 번에 1칸 또는 2칸씩 오를 수 있을 때, n번째 계단까지 오는 경우의 수는?

```
dp[n] = dp[n-1] + dp[n-2]
```

n번째 계단에 도착하는 방법은 "n-1번째에서 1칸 오르거나" 또는 "n-2번째에서 2칸 오르거나" 둘 중 하나이기 때문입니다.

**점화식을 세우는 순서**
1. 작은 예시 몇 개를 직접 손으로 풀어본다 (n=1, 2, 3 정도)
2. "지금 상태가 이전의 어떤 상태(들)로부터 만들어지는지" 관찰한다
3. 그 관계를 수식으로 표현한다

<br>

### 5. 1차원 DP vs 2차원 DP

**1차원 DP**: 상태가 인덱스 하나로 표현되는 경우 (`dp[i]`). 계단 오르기, 피보나치가 대표적입니다.

**2차원 DP**: 상태를 표현하려면 조건이 두 개 필요한 경우 (`dp[i][j]`). 예를 들어 배낭 문제는 "몇 번째 물건까지 고려했는지"(`i`)와 "지금까지 사용한 무게"(`j`) 두 가지를 같이 관리해야 합니다.

```python
# 배낭 문제 형태의 뼈대
dp = [[0] * (capacity + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(capacity + 1):
        # dp[i][j] = i번째 물건까지 고려했을 때, 무게 j 이하로 담을 수 있는 최댓값
        ...
```

<br>

### 6. DP인지 아닌지 판별하는 법

아래 두 조건을 같이 만족하면 DP를 의심해봐야 합니다.

- **최적 부분 구조**: 큰 문제의 답이 작은 문제들의 답으로 구성된다
- **중복되는 부분 문제**: 같은 작은 문제가 여러 번 반복해서 등장한다

이 둘 중 하나라도 없으면 DP가 아니라 다른 접근(그리디, 완전탐색 등)이 필요할 수 있습니다.
