# SKALA PS 2026

프로그래머스 기반 SKALA 판교 2반 알고리즘 스터디 저장소입니다.

<br>

## 📌 진행 방식

1. 매주 초 `Issue`로 그 주차 문제가 공지됩니다.
2. 각자 브랜치를 생성해 문제를 풉니다.
3. **마감일 전까지 자유롭게 PR을 올립니다.** (문제 하나씩 올려도 되고, 모아서 올려도 됩니다. 개수 제한 없음)
4. PR 코멘트로 코드 리뷰를 진행합니다.
5. 리뷰 완료 후 `main` 브랜치로 merge합니다.
> 질문이나 막히는 부분은 Issue로 자유롭게 남겨주세요.

<br>

## 📁 폴더 구조

```
week1-array-string/
├── README.md                 # 해당 주차 개념 정리
├── problem01-문제이름1/
│   ├── hong.py
│   └── kim.java
├── problem02-문제이름2/
│   ├── hong.py
│   └── kim.java

personal/
├── hong/
│   └── 개인문제이름1.py
├── kim/
```

- 주차 폴더 안 `README.md`에는 그 주 핵심 개념이 정리되어 있습니다.
- 같은 문제를 여러 명이 풀 경우, 문제 폴더 하나에 각자 이름으로 파일을 올립니다.
- 스터디 커리큘럼 외에 개인적으로 더 풀고 싶은 문제는 `personal/본인이름/` 폴더에 올립니다.

<br>

## 🙋 개인 추가 학습

- 커리큘럼과 무관하게 개인적으로 더 푼 문제는 `personal/본인이름/`에 올려주세요.
- **커리큘럼 문제와 동일하게 PR + 리뷰를 거쳐 merge합니다.** (별도 예외 없음)
- 파일명은 자유입니다. (예: `플랫폼-문제이름.py`)
